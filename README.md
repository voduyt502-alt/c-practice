# c-practice

C exercises for beginners. Each file is one exercise.

## Exercises

| File | Description |
|---|---|
| bai1.c | Print name and class |
| bai2.c | Basic arithmetic (sum, difference, product, quotient) |
| bai3.c | Circle circumference and area |
| bai4.c | Check even or odd |
| bai5.c | Maximum of three numbers |
| bai6.c | Grade classification from score |
| bai7.c | Multiplication table |
| bai8.c | Sum from 1 to n |
| bai9.c | Count digits of an integer |
| bai10.c | Check prime number |
| bai11.c | Prime check using a function |
| bai12.c | Array sum and maximum |
| bai13.c | Reverse an array |
| bai14.c | Count even and odd numbers |

## How to build and run

```
gcc -Wall -Wextra bai1.c -o bai1
./bai1
```
